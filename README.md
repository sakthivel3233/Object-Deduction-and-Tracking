# Object Detection and Tracking Project

A real-time computer vision application that detects objects in a video feed and tracks them across frames.

## 🚀 Features
* Real-time vehicle and pedestrian detection.
* ID assignment to prevent duplicate counting.
* High frame-rate processing.

## 🛠️ Built With
* **Python**
* **OpenCV** (for video processing)
* **Ultralytics YOLO** (for object detection)

## 📦 Installation
Clone the repository and install the required packages:
```bash
git clone https://github.com
cd sakthivel3233
pip install -r requirements.txt
```

## 💻 How to Run
Run the main script using a sample video or your webcam:
```bash
python main.py --source video.mp4
```
